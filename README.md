# Plan DCG 2027

Mon planning de révision du DCG (UE1, 5, 7, 8, 9, 12 et 13), qui s'adapte à ce que j'ai fait ou pas.

**Ouvrir l'appli :** https://yoeldahan.github.io/plan-dcg/

- `index.html` : l'appli (installable sur l'iPhone : Safari → Partager → « Sur l'écran d'accueil »)
- `weeks/` et `plan.json` : le plan semaine par semaine
- branche `data` : ma progression (`state.json`) et le mot du coach (`coach.json`)

*Pas à pas, jusqu'au sommet.*
